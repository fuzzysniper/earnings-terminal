# EARNINGS Terminal v0.2

Mobile-first event-driven financial culture terminal for EARNINGS / $BEAT.

## Current product
- Market 001: GME print archive
- Market 002: ORCL / ADBE AI doubleheader
- Local BEAT/MISS sentiment voting
- Copyable $BEAT Solana contract address
- Pump.fun and @earningsdot links
- Responsive iPhone-first interface
- Event ledger
- No fabricated live market data

## Production
Designed to deploy as a static site on Netlify directly from the `main` branch.

- Build command: none
- Publish directory: repository root (`.`)
- Entry point: `index.html`

Once Netlify is connected to this GitHub repository, every commit to `main` should trigger a production deploy automatically.

## Product principle

PREVIEW → PRINT → REACTION → NEXT

Consensus estimates and event data should be verified before publication.
